Oque é Git e Git Hub?

Git

O git é um sistema de controle de versões que permite acompanhar as alterações realizadas nos arquivos

Com ele, podemos realizar alterações, recuperar versões anteriores e trabalhar em equipe.

GitHub

O GitHub é uma plataforma online que permite armazenar e compartilhar repositórios Git.

Por meio dele, podemos compartilharprojetos, colaborar com outros desenvolvedores e visualizar o histórico de alterações
